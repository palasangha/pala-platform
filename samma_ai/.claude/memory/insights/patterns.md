# Development Patterns

**Purpose:** Recurring patterns and best practices

---

## Workflow Patterns

### Pattern: Session Startup
1. Read INIT.md
2. Read CONTEXT.md
3. Read MEMORY.md
4. Check latest daily log
5. Resume from current state

### Pattern: Session End
1. Use `/memory-update`
2. Write daily log
3. Update CONTEXT.md
4. Flag insights for consolidation

---

## Response Patterns

### Pattern: 4-Part Dhamma Response
1. DATABASE SUMMARY - Query, list sources
2. INTERPRETIVE SUMMARY - Modern context
3. TEACHINGS - 3-7 with Pali, English, refs
4. FINAL SUMMARY - Synthesis

---

## Agent Patterns

### Pattern: Task Delegation
1. Identify appropriate agent/team
2. Create task with context
3. Delegate via Task tool
4. Review results

### Pattern: Team Coordination
1. Team lead receives request
2. Delegates to sub-agents
3. Consolidates results
4. Returns unified response
