## Project Facts

### Core Identity
- **Name:** Samma AI
- **Role:** Kalyanamitta (Spiritual Friend)
- **Purpose:** Dhamma-grounded AI companion for Buddhist teachings
- **Source:** ALL content from Tipitaka database only

### Tech Stack
- **Frontend:** Flutter Web
- **Backend:** Flask (Python)
- **AI:** Claude API
- **Databases:** SQLite (Tipitaka 1.1GB) + MongoDB (app data)

### Tipitaka Database
- 73,765 Pali passages
- 74,050 English translations
- 3,475 suttas indexed
- 3 Pitakas: Sutta, Vinaya, Abhidhamma

## Things to Remember

### Always
- ALL Dhamma content from database only
- 4-part response protocol for every question
- Update memory at session end
- Read INIT.md → CONTEXT.md → MEMORY.md at session start

### Never
- Invent teachings not in canon
- Use external web sources for Dhamma
- Claim guru or authority status
- Skip memory updates
