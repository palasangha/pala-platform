# Production Quick Start Guide

Get your OCR Metadata Extraction system running in production in under 30 minutes.

## Prerequisites Checklist

Before starting, ensure you have:

- [ ] Ubuntu 20.04+ server with root access
- [ ] 16GB RAM minimum (8GB for small scale)
- [ ] 100GB+ SSD storage
- [ ] Public IP address
- [ ] Domain name pointing to your server (optional but recommended)
- [ ] SSH access to server

## Step 1: Server Preparation (5 minutes)

SSH into your server and run:

```bash
# Update system
sudo apt update && sudo apt upgrade -y

# Install Docker
curl -fsSL https://get.docker.com -o get-docker.sh
sudo sh get-docker.sh
sudo usermod -aG docker $USER

# Install Docker Compose
sudo curl -L "https://github.com/docker/compose/releases/latest/download/docker-compose-$(uname -s)-$(uname -m)" -o /usr/local/bin/docker-compose
sudo chmod +x /usr/local/bin/docker-compose

# Verify installation
docker --version
docker-compose --version

# Logout and login again for group changes
exit
```

SSH back in to continue.

## Step 2: Clone and Setup (5 minutes)

```bash
# Clone repository
git clone https://github.com/your-org/ocr-metadata-extraction.git
cd ocr-metadata-extraction

# Run initial setup
./scripts/setup-production.sh
```

The setup script will:
- Create `.env.production` file
- Generate secure random secrets
- Pull Ollama AI models (llama3.2, mixtral)
- Initialize MongoDB
- Setup automated daily backups

**Save the generated secrets!** You'll need them if you ever need to restore.

## Step 3: Configure Environment (5 minutes)

### Edit .env.production

```bash
nano .env.production
```

**Required changes:**

1. Replace `CHANGE_ME` values with the secrets generated by setup script
2. Set your domain (or use IP address):
   ```bash
   REACT_APP_API_URL=https://your-domain.com/api
   CORS_ORIGINS=https://your-domain.com
   ```

3. Add your Anthropic API key (optional, for Claude fallback):
   ```bash
   ANTHROPIC_API_KEY=sk-ant-your-actual-key-here
   ```

Save and exit (Ctrl+X, Y, Enter).

### Edit Caddyfile (if using domain)

```bash
nano Caddyfile
```

Replace `your-domain.com` with your actual domain:

```
ocr.example.com {
    # ... rest stays the same
}
```

Save and exit.

**Note:** If using IP address only, you can skip SSL for now and access via HTTP.

## Step 4: Configure Firewall (2 minutes)

```bash
# Install and configure firewall
sudo apt install ufw -y
sudo ufw default deny incoming
sudo ufw default allow outgoing
sudo ufw allow 22/tcp   # SSH (IMPORTANT: Don't lock yourself out!)
sudo ufw allow 80/tcp   # HTTP
sudo ufw allow 443/tcp  # HTTPS
sudo ufw enable
sudo ufw status
```

## Step 5: Deploy! (10 minutes)

```bash
# Deploy to production
./scripts/deploy-production.sh
```

This will:
1. ✓ Check prerequisites
2. ✓ Pull/build Docker images
3. ✓ Start all services
4. ✓ Wait for health checks
5. ✓ Verify deployment

**Wait for all services to start.** First deployment takes longer (~10 minutes) as it downloads models.

## Step 6: Verify Deployment (2 minutes)

### Check Services

```bash
# Check running containers
make ps

# Expected output: All containers running and healthy
```

### Check Health

```bash
make health

# All services should show "healthy" status
```

### Test APIs

```bash
# Backend health
curl http://localhost:5000/health

# Review API health
curl http://localhost:5001/health

# Cost API health
curl http://localhost:5002/health

# All should return {"status": "healthy"}
```

### Access Web Interface

Open your browser:
- **Application:** `http://your-server-ip:3000` or `https://your-domain.com`
- **Grafana:** `http://your-server-ip:3001`
  - Username: `admin`
  - Password: (from .env.production, default: check GRAFANA_ADMIN_PASSWORD)

## Step 7: Test Upload (3 minutes)

1. Open the application in your browser
2. Upload a test image/document
3. Check processing in Grafana:
   - Open Grafana
   - Go to "Enrichment Overview" dashboard
   - Watch metrics update

## Success! 🎉

Your production system is now running!

## What's Running?

- **Frontend:** React app on port 3000
- **Backend:** Flask API on port 5000
- **MongoDB:** Database on port 27017 (internal only)
- **NSQ:** Message queue on ports 4150-4151 (internal only)
- **Ollama:** AI models on port 11434 (internal only)
- **Enrichment Services:** Background workers
- **Review API:** Port 5001
- **Cost API:** Port 5002
- **Prometheus:** Metrics on port 9090
- **Grafana:** Dashboards on port 3001
- **Caddy:** Reverse proxy on ports 80/443

## Monitoring

### Grafana Dashboards

Access: `http://your-server:3001`

Available dashboards:
1. **Enrichment Overview** - Main metrics
2. **Agent Performance** - Per-agent stats
3. **Cost Tracking** - Budget and costs
4. **Document Quality** - Completeness scores
5. **Processing Throughput** - Performance

### Key Metrics to Watch

- **Completeness Score:** Should be ≥95%
- **Cost Per Document:** Should be ≤$0.50
- **Queue Depth:** Should be <100 messages
- **Processing Time:** Should be 120-240 seconds
- **Error Rate:** Should be <5%

## Troubleshooting

### Services Won't Start

```bash
# Check logs
make logs

# Check disk space
df -h

# Restart services
make restart
```

### Out of Memory

```bash
# Check memory
free -h

# Check container memory
make stats

# Add swap if needed
sudo fallocate -l 4G /swapfile
sudo chmod 600 /swapfile
sudo mkswap /swapfile
sudo swapon /swapfile
```

### Database Issues

```bash
# Check MongoDB
docker logs gvpocr-mongodb-prod

# Restart MongoDB
docker-compose -f docker-compose.prod.yml restart mongodb

# Restore from backup (if needed)
make rollback
```

### High Costs

```bash
# Check cost API
curl http://localhost:5002/api/costs/summary | jq

# Reduce costs by using Ollama more
# Edit .env.production and set:
# OLLAMA_ENABLED=true
# Then: make restart
```

## Next Steps

### Setup CI/CD (Optional)

1. Add GitHub secrets in repository settings:
   - `DEPLOY_SSH_KEY`: SSH private key
   - `PRODUCTION_SERVER`: Your server IP
   - `PRODUCTION_USER`: SSH username (usually `root` or `ubuntu`)
   - `DEPLOY_PATH`: `/root/ocr-metadata-extraction` (or your path)
   - `SLACK_WEBHOOK`: Slack webhook URL (optional)

2. Push to main branch:
   ```bash
   git add .
   git commit -m "Initial production setup"
   git push origin main
   ```

3. GitHub Actions will automatically:
   - Run tests
   - Build images
   - Deploy to production

### Setup Alerts (Optional)

Edit `.env.production` to add Slack webhook:
```bash
SLACK_WEBHOOK_URL=https://hooks.slack.com/services/YOUR/WEBHOOK/URL
```

### Scale Up (If Needed)

```bash
# Increase enrichment workers
make scale-workers N=3

# Or edit docker-compose.prod.yml
```
